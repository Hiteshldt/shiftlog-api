## Looked at and decided it was not a defect

- **`load_dotenv()`**: the default is `override=False`, so real environment variables already win over `.env`.
- **Derived fields in a request body**: Pydantic ignores unknown fields by default, which is what the contract asks for ("if a client sends one, ignore it"), so I did not add `extra="forbid"`.
- **Sync PyMongo with plain `def` endpoints**: FastAPI runs these in a thread pool, and `MongoClient` is thread-safe with its own connection pool. Switching to Motor would add complexity without changing correctness.
- **`doc.pop("_id", None)` after `insert_one`**: correct that `_id` must not leak; I replaced it with explicit serializers, but the idea was right.
- **`IST = timezone(timedelta(hours=5, minutes=30))`**: a fixed offset is right for IST (no daylight saving), so no time zone database is needed.
- **Date filters as string comparison** in `list_attendance`: correct, because `YYYY-MM-DD` strings sort in calendar order.
